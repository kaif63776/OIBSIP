# Level 1 — Task 2: Personal Portfolio Website

A personal portfolio website showcasing professional profile details, technical skills, and featured projects, built for the Oasis Infobyte Internship Program (OIBSIP).

## 🚀 Features
* **Hero & Profile Section:** Professional introduction, status badge, and avatar profile placeholder.
* **About Me Section:** Background summary and core engineering interests.
* **Technical Skills Grid:** Visual cards representing core programming skills and frameworks.
* **Featured Projects Section:** Direct repository links to developed projects (including QuizVerse).
* **Responsive Layout:** Clean dark-themed modern design adaptable to all screen sizes.

## 🛠️ Tech Stack
* HTML5
* CSS3 (Custom Styling & Flexbox)
