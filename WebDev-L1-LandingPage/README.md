# Level 1 — Task 1: Landing Page (Web Development & Designing)

A visually polished static product landing page built as part of the Oasis Infobyte Internship Program (OIBSIP).

## 🚀 Features
* **Sticky Navigation Bar:** Fixed top navbar with smooth links to main sections.
* **Hero Section:** Engaging headline, subheadline, and a prominent Call-To-Action (CTA) button.
* **Content Sections:** Highlighted product features and user testimonials.
* **Responsive Design:** Built using CSS Flexbox/Grid to ensure seamless viewing across desktop, tablet, and mobile devices.

## 🛠️ Tech Stack
* HTML5
* CSS3 (Flexbox & Grid)
